A travel poster for LUMARIS, a place that isn't there: a dusk bay where the lagoon glows turquoise, a striped lighthouse sweeps its beam across the sunset, white cliff-houses stack on the left headland, and sailboats with lanterns drift on the shining water — the invented place's name set large in the starry sky, promising a stay where the sea lights the night. The poster is drawn deterministically with Pillow (gen_poster.py) and main.ts copies the resulting 1024x1024 PNG to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
