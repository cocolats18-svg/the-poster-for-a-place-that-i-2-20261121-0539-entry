A travel poster for LUMARIS — a place that isn't there. At dusk its lagoon glows turquoise under a coral sunset, a striped lighthouse on the right cliff sweeps its beam across the sky, white cliff-houses cluster on the left headland, and lantern-lit sailboats drift on the shining water, with the invented place's name set large in the starry sky above the promise "WHERE THE SEA LIGHTS THE NIGHT". The poster is drawn deterministically with Pillow by gen_poster.py, and main.ts copies the resulting 1024x1024 PNG to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
